# Mycelia (العربية)

**دماغ اصطناعي بتوصيلات ناشئة يتعلّم الفرنسية.**

‏Mycelia ليس كومة من الطبقات، بل مستعمرة من عُقد صغيرة مستقلة. تتحدّث برسائل،
وتختار بنفسها مَن تخاطب، وتنشئ مشابك عندما تريد الوصول إلى أحد، وتقطعها عندما
تجوع، وتموت عندما لا يصل إليها شيء، وتعود تمامًا كما كانت عندما تناديها رسالة.
الرهان هو عكس Transformer: قد يأتي الذكاء من **البنية الديناميكية** (عُقد تولد
وتموت وتتخصّص) لا من الحجم الخام. النموذج الحيوي هو دماغ ذبابة الفاكهة الذي رسمه
FlyWire.

الحالة: المراحل الست منفّذة ومختبَرة وقابلة للمراقبة الحيّة في cockpit داخل
المتصفح. التوثيق الكامل: [README.md](../README.md)،
[README.fr.md](README.fr.md).

## البدء السريع

```bash
pip install -r requirements.txt
python scripts/train_tokenizer.py              # مجموعة LeCarnet + BPE بـ 10 000
python mycelia/train.py --data text --scale 0  # الفرنسية، 10 000 خطوة
python scripts/dashboard.py --train --data text --scale 0
# → http://127.0.0.1:8080
python -m pytest tests -q                      # 32 اختبارًا
```

## الأفكار الأساسية

* عقدة بعرض 32 تملك نحو 6 400 معامل؛ و140 000 عقدة هي الحد الرمزي، ولا تُستخدم
  مصفوفة كثيفة أبدًا.
* التوصيل يُخزَّن كـ `edge_index [2, 20 000]` مع العدّاد `ne`، لا N×N.
* الموجّه يعمل بالاستعلام/المفتاح مع مرشّحين مُعيَّنين: O(dim) لكل عنوان، لا O(N).
* الحواف تولد داخل forward بميزانية 8 لكل خطوة؛ والموت على مرحلتين، والمقبرة
  تعيد الأوزان الدقيقة.
* يعرض cockpit الرسم وهو يتوصّل، والنبضات، وعلامات الحياة السبع، والمحادثة رمزًا
  برمز.
