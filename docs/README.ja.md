# Mycelia（日本語）

**創発的な配線を持つ人工脳が、フランス語を学ぶ。**

Mycelia は層の積み重ねではありません。小さな自律ノードのコロニーです。ノード
同士はメッセージで会話し、誰に話しかけるかを自分で決め、届きたい相手がいれば
シナプスを生やし、使われなければ切り、何も届かなくなれば死に、メッセージに
呼ばれれば元とまったく同じ重みで戻ってきます。Transformer とは逆の賭けです。
知能は生の規模ではなく、**動的な構造**（生まれ、死に、専門化するノード）から
来るかもしれない。生物学的なモデルは FlyWire が地図化したショウジョウバエの脳
です。

状態：6 つの段階はすべて実装・テスト済みで、ブラウザのコックピットでライブに
観察できます。完全な文書：[README.md](../README.md)、
[README.fr.md](README.fr.md)。

## クイックスタート

```bash
pip install -r requirements.txt
python scripts/train_tokenizer.py              # LeCarnet コーパス + 10 000 BPE
python mycelia/train.py --data text --scale 0  # フランス語、10 000 ステップ
python scripts/dashboard.py --train --data text --scale 0
# → http://127.0.0.1:8080
python -m pytest tests -q                      # 32 テスト
```

## 要点

* 幅 32 のノードは約 6 400 パラメータ。140 000 ノードは象徴的な上限で、密行列は
  決して使いません。
* 配線は `edge_index [2, 20 000]` と使用数 `ne`。N×N はありません。
* ルーターはクエリ/キーとサンプリング候補：アドレスあたり O(dim)、O(N) では
  ありません。
* 辺はフォワード中に生まれ（1 ステップ最大 8 本）、死は 2 段階。墓地は正確な
  重みを返します。
* コックピットは配線が進むグラフ、信号のパルス、7 つの生命兆候、トークンごとの
  会話をリアルタイムで表示します。
