# Mycelia (русский)

**Искусственный мозг с возникающими связями, который учит французский.**

Mycelia — это не стопка слоёв, а колония маленьких автономных узлов. Они
разговаривают сообщениями, сами выбирают, к кому обратиться, отращивают синапсы,
когда хотят кого-то достичь, обрезают их, когда те голодают, умирают, когда их
ничто не достигает, и возвращаются в точности такими, какими были, когда
сообщение их зовёт. Ставка противоположна Transformer: интеллект может возникать
из **динамической структуры** (узлы рождаются, умирают, специализируются), а не
из грубого размера. Биологическая модель — мозг дрозофилы, картированный FlyWire.

Состояние: все шесть этапов реализованы, протестированы и наблюдаемы вживую в
браузерном кокпите. Полная документация: [README.md](../README.md),
[README.fr.md](README.fr.md).

## Быстрый старт

```bash
pip install -r requirements.txt
python scripts/train_tokenizer.py              # корпус LeCarnet + BPE на 10 000
python mycelia/train.py --data text --scale 0  # французский, 10 000 шагов
python scripts/dashboard.py --train --data text --scale 0
# → http://127.0.0.1:8080
python -m pytest tests -q                      # 32 теста
```

## Ключевые идеи

* Узел шириной 32 имеет ~6 400 параметров; 140 000 узлов — символический предел,
  плотная матрица не используется никогда.
* Связи хранятся как `edge_index [2, 20 000]` плюс счётчик `ne`, а не N×N.
* Маршрутизатор — запрос/ключ с выборочными кандидатами: O(dim) на адрес, не O(N).
* Рёбра рождаются внутри forward с бюджетом 8 на шаг; смерть в два этапа, а
  кладбище возвращает точные веса.
* Кокпит показывает, как граф обрастает связями, импульсы, семь признаков жизни и
  чат по одному токену.
